# 创/科/北涨停首板次日低开策略 (gem_star_limitup_low_open)

## 1. 策略概览

| 指标 | 数值 |
|------|------|
| CAGR | **+202.40%** |
| 交易笔数 | 458 |
| 胜率 | 55.02% |

**一句话总结**：创业板/科创板/北交所股票昨日涨停（首板，+20%/+30%），今日低开-2%~-8%时在H1开盘买入，利用涨停打开后恐慌性低开制造的超跌机会，配合2pp trailing stop快速锁利+6%硬止损兜底，捕获涨停首板次日的反弹利润。

## 2. 核心逻辑

### 信号条件（当日H1开盘时实时判断）

| 条件 | 要求 | 含义 |
|------|------|------|
| 板块 | 创业板(sz.30) / 科创板(sh.688) / 北交所(bj.) | 20%/30%涨跌幅=高波动 |
| 昨日涨停 | close/preclose >= 涨停比例(1.20/1.30) | 涨停确认极强势 |
| 首板确认 | 前日非涨停 | 排除连板票（连板风险极高） |
| 昨日换手率 | >= 5% | 排除一字板（无法参与） |
| 今日低开 | -8% < open_rate < -2% | 恐慌性低开=入场时机 |
| 近5日累计涨幅 | < 40% | 排除连续暴涨过热票 |
| 非ST | 是 | 排除退市风险 |

### 买入时机

- **时点**：当日Hour1 开盘（9:30）
- **价格**：H1_open（集合竞价结束价）
- **前提**：满足所有信号条件后立即买入

### 卖出规则

| 类型 | 触发条件 | 成交价 | 说明 |
|------|----------|--------|------|
| 硬止损 | 盘中LOW <= 买入价×0.94 | 买入价×0.94或open(取低) | -6%绝对保护 |
| Trailing Stop | 从peak回落 >= 2.0pp | 买入价×(1+(peak-2.0)/100) | 快速锁利核心 |
| 到期平仓 | hours_held >= 12 且 hour==4 | H4_close | 最长持有3天 |

**Trailing Stop机制详解**：
- 追踪持仓期间最高盈利点(peak_pct)
- 当盈利从peak回落2.0个百分点时触发卖出
- 例：peak达到+8%，回落到+6%时触发，锁定+6%利润
- T+1合规：买入当日不卖出

### 选股排序规则

- **低开幅度升序（低开越深越优先）**：恐慌越大=超跌越深=反弹空间越大

## 3. 市场心理学/行为金融原理

### 对手方是谁？

**昨日封板追涨但今日恐慌出逃的打板客**。涨停首板意味着昨日最高价买入者全部被锁在涨停价（因为只有涨停价成交），次日低开-2%以上时，这批打板资金面临即时亏损，集中恐慌性抛售形成超跌。

### 利用了什么心理偏差？

1. **损失厌恶放大效应**：打板客买入成本=涨停价，低开-2%即浮亏-2%，在损失厌恶(×2.5)作用下主观感受等同-5%亏损，触发非理性止损。

2. **锚定涨停预期的坍塌**：打板客的预期是"涨停板打开→次日继续冲高"，低开直接粉碎预期，情绪从贪婪瞬间切换为恐惧。

3. **首板vs连板的概率误判**：市场对首板次日的真实统计分布（多数微涨/微跌）与打板客幻想的"连板"预期严重不对称，低开修正了这种误判。

### 为什么alpha不会很快消失？

1. **涨停板的心理黏性**：打板是A股散户最热衷的策略之一，持续为本策略提供对手方。
2. **20%涨跌幅的恐惧倍增**：创/科/北交所-20%的下限使得低开后恐慌更剧烈，普通投资者不敢接盘。
3. **首板筛选的独特性**：市场上绝大多数"涨停次日"策略不区分首板/连板，本策略通过首板过滤排除了高风险连板票。

## 7. 风险提示

### 最大回撤场景
- MDD 72.33%，主要发生在创/科板连续系统性下跌期间
- 涨停次日低开后继续跌停（-20%）的极端情况下单笔可亏-6%（硬止损保护）

### 策略失效的市场环境
- **涨停生态崩溃**：监管严打炒作导致涨停板大幅减少，信号枯竭
- **创/科板系统性暴跌**：全板块普跌时低开后不反弹，持续杀跌
- **连板行情消失**：市场无板块效应时，首板次日无资金接力

### 实盘注意事项
1. **开盘竞价参与**：需在9:25前挂单，竞价结束后自动成交
2. **板块识别**：严格只交易创业板(30xxxx)/科创板(688xxx)/北交所
3. **高波动心理准备**：20%涨跌幅意味着单日波动巨大
4. **trailing需实时监控**：每小时级bar结束后判断是否触发trailing stop
5. **首板确认**：必须验证前日非涨停，连板票风险性质完全不同
6. **资金量限制**：创/科小盘股流动性有限，建议单笔不超过该股日均成交额的1%
