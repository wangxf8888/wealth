# 策略研发索引

## 项目目标
研发T+1合规的A股短线交易策略，目标年化≥100%

## 研发方法论
1. 形成策略思路
2. 单月脚本扫描（候选股+前后5日hour级OHLC）
3. 分析最优买卖时机（日内表现）
4. **T+1/T+2可执行收益验证**（关键！日内收益≠可执行收益）
5. 扩展至2021-2026六年验证
6. 对接回测引擎，多仓位完整回测

## 关键教训
> ⚠️ A股T+1规则下，日内研究收益 ≠ 可执行收益。所有策略必须用T+1/T+2真实退出收益衡量。
