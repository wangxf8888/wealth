## 核心逻辑

### 市场心理
昨日大幅冲高回落（上影线远长于下影线）的股票，意味着盘中有大量跟风买入者被套在高位。由于A股T+1制度，这些当日追高的资金次日才能卖出。当次日恐慌性低开时，卖压集中释放后形成超跌，低开价格往往已过度反映了利空预期，此时入场等待修复性反弹。

### 信号条件（盘后生成候选池）
1. **振幅强度2(amp2) >= 4%**：
   - 计算方式：(上影线长度 - 下影线长度) / 前收盘价 × 100
   - 上影线 = HIGH - max(OPEN, CLOSE)
   - 下影线 = min(OPEN, CLOSE) - LOW
   - amp2 >= 4% 意味着上影线比下影线长出至少4%的前收盘价，即"冲高回落"形态明显
2. **非ST股**
3. **非北交所股票**
4. **换手率**: 1% <= turn <= 30%（过滤僵尸股和异常高换手）
5. **成交额**: >= 5000万（保证流动性）

### 买入条件（T+1日 hour1）
1. **必须低开**：open_rate < 0%（恐慌性低开 = 卖压释放 = 入场时机）
2. **今日不能涨停开盘**：排除无法买入的情况
3. **卖出当天不买新股**：避免同日频繁交易
4. **买入价**: hour1 open（9:30集合竞价结束价）

### 排序规则
- 先按 amp2 降序取 top 5（上影越大 = 冲高回落越剧烈 = 反弹空间越大）
- 在 top 5 中选换手率最低的 1 只（低换手 = 筹码集中 = 弹性大）

### 卖出条件
| 类型 | 触发条件 | 成交价 |
|------|----------|--------|
| 止盈 | 盘中HIGH >= 买入价×1.05 | 买入价×1.05（精确触发） |
| 止损 | 盘中LOW <= 买入价×0.75 | 买入价×0.75（精确触发, 六年回测零触发=纯安全网） |
| 到期 | hours_held >= 8 且 hour==4 | D+2 H4 close价（买入日不计满8小时, 实际到期在D+2尾盘） |
| Gap止盈 | 开盘price已>=+5% | 以open成交 |
| Gap止损 | 开盘price已<=-25% | 以open成交 |

**注**: 当同一根K线TP和SL同时触发时（HIGH>=TP且LOW<=SL），保守处理以SL成交。

## 策略原理

### 为什么能盈利
1. **T+1制度创造的结构性机会**: 昨日冲高追入的资金当天无法卖出，次日集中抛压导致低开。但这种低开已经过度反映了利空（恐慌情绪放大），形成短期超卖。
2. **大上影线 = 被套资金多**: amp2>=4%确保了昨日有大量资金在高位被套，这些资金的集中抛售在次日早盘已完成，卖压出尽后自然反弹。
3. **低换手率选股的精妙**: 在amp2最大的top5中选换手最低的股，意味着虽然冲高回落但筹码并未大量换手，主力资金仍在（锁仓），反弹动力更强。
4. **紧止盈+极宽止损**: 5%止盈匹配54%胜率，快速兑现利润；-25%止损实质为极端安全网（六年零触发），亏损仓位由到期机制终止——释放了被-15%旧止损"洗出后反弹"的仓位。

### 失效场景
- 2023年熊市年度收益-18.13%（v2口径；SL放宽后回撤加深）
- 系统性下跌时"低开反弹"逻辑失效，低开后可能继续杀跌

## 实盘执行
- 候选股生成时间：盘后17:00（计算当日所有股票的amp2值，筛选>=4%的候选）
- 决策时间：次日9:25（确认是否低开）
- 买入执行：H1 open（9:30集合竞价结束价）
- 持仓周期：最多D+1全天（8小时）
- 关键参数：amp2>=4%，必须低开，top5选换手最低

## 风险提示
- MDD 61.49%较大（SL放宽代价+2.39pp），建议配合其他策略分散风险
- SL=-25%六年零触发，最深单笔亏损-23.01%（经到期退出）——尾部风险由到期机制而非SL控制
- 2023年-18.13%，熊市中SL放宽允许更深回撤
- 止盈仅5%较窄，可能错过大幅反弹（但保证了高频兑现）
- 同一根K线TP/SL同时触发时按SL处理，保守估计可能略低估实际收益
- 该策略信号频率高(509笔/5.5年≈92笔/年)，适合频繁交易者
