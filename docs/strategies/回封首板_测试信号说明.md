## 一、策略规则通俗版

### 什么样的股票会触发信号？（当日15:10盘后判定）
1. **首板**: 昨天没涨停，今天涨停（不追连板，只做首板）；
2. **首封时刻在10:05-11:30之间**（T3时段）：不要开盘秒板（太强追不进），也不要午后偷袭板（太弱不可靠），
   要的是早盘经过充分交锋后封住的板；
3. **开板≥1次后重新封住**: 盘中被砸开过至少一次，又被资金顽强买回封死——"回封"
   是资金决心的试金石；
4. **收盘封死**: 尾盘必须仍封在涨停价上（收盘价=涨停价）；
5. **排除项**: ST/退市风险股、北交所、上市不足90天的次新股、一字板（开盘即封从未打开的买不到）。

### 买卖时点（D+1模拟交易）
- **模拟买入**: 次日（D+1）开盘价买入；若开盘就涨停，追不进，放弃该笔（不记账为交易）；
- **模拟卖出**（三选一，先到先出）:
  - 止盈：股价涨到买入价+5% → 以+5%价位卖出（D+2起按日级判定，止盈优先，跳空高开按开盘价）；
  - 止损：股价跌到买入价-8% → 以-8%价位卖出（跳空低开按开盘价）；
  - 兜底：第3个交易日（D+3）收盘无条件卖出；
- 净收益口径统一扣除双边0.1%交易费用。

### 每日频控
每天最多推送3条通知；若信号超过3只，按**首封时刻早者优先**（早封的板更强），
其余信号仍全部落盘记账，只是不推送。

## 三、数据链与安全机制

- **数据源**: data/board_process/events_YYYYMMDD.jsonl（board_lab分钟实采，60秒轮询全A盘口）——
  与Yale回测用的minute.db口径做过数据层对拍（覆盖窗一致率97.6%，差异均为60s轮询对5分钟bar边界的已知近似）；
- **收盘封死自算**: 不信任采集器的final_state/at_limit标志（8/7实测尾盘集合竞价期会把59只真封死中的30只误标为炸板），改用收盘快照价+昨收自算涨停价判定；
- **安全退出**: events文件缺失（board_lab故障）/ 覆盖不足（采集器晚启动）/ 未收工 → 记日志安全退出，当日不发信号，绝不带病输出；
