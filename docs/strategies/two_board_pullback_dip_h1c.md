## 2. 核心逻辑

### 选股条件（D1开盘前，基于D0及更早数据，无未来数据）

| 条件 | 要求 | 含义 |
|------|------|------|
| 恰2板 | 最近涨停日连板数==2（D-1/D-2 或 D-2/D-3 连板，此前一日未板） | 2板=题材确认但未过热 |
| 第2板非一字 | 第2个涨停日 open < 涨停价 | 一字板无换手，次日回调结构不同 |
| 断板回调 | 回调1~2天，期间不再涨停 | 浅调洗浮筹而非趋势反转 |
| D0浅调 | 回调期收盘跌幅温和（形态由连板/未板序列约束） | 深杀(< -5%)属破位，排除 |
| D1竞价低开 | -4% <= open_rate < 0 | 恐慌折价=入场时机；低开>-4%防破位 |
| 基础过滤 | 非ST、非北交所、上市>=20根K线 | 流动性与合规 |

### 买入

- **时点**：D1 Hour1 开盘（9:30，竞价结束价 H1_open）
- **排序**：更低开优先（open_rate 升序）——研究口径 top1 +0.91%/日、2021-2026六年全正
- **保护**：开盘已涨停不追买（策略+引擎双保险）

### 卖出（本变体核心）

| 类型 | 触发条件 | 成交价 | 说明 |
|------|----------|--------|------|
| 定时了结 | D2 Hour1 结束 | D2 H1_close | 唯一主动退出路径 |
| 顺延兜底 | D2 H1跌停封死/缺数据 | 之后任意小时开盘价尽快卖出 | reason=deferred |

无盘中止盈/止损（`take_profit_pct/stop_loss_pct` 声明极宽仅为满足框架读取，永不触发）。

### slot 当小时复用机制（`sell_day_no_buy = False`）

引擎每小时**先卖后买**：D2 H1 卖出 → 同一小时内该 slot 立即空出 → 若当日有新信号，H1 内即可再买入。原理：
- 对照版(hold1, D2收盘卖)的 slot 隔日才空，只能吃到约一半信号日；
- h1c 卖买同小时无缝衔接 → 笔数 641→1250（1.95x），**94%的买入日=卖出日**；
- 引擎语义为双条件拦截（引擎标志 AND 策略属性），策略侧置 False 即放行，无需 `--sell-first`。

> ⚠️ **实盘资金流警示（2026-07-31）**：回测是"先卖后买"（回款先到），实盘是"9:30先买、10:30后卖"——复用买入实际动用其它空槽备付现金，满信号日会挤占正当槽位（P0-1缺陷，修复方案待裁决）。详见 `docs/trading_mechanism.md` §3.3.1 与 `data/realtime/P0_DIAGNOSIS_20260731.md`。

## 7. 风险与边界

1. **单策略MDD 79.92% 偏高**：高周转+无止损的裸暴露；组合内（5策略等权再平衡，单策略仓位=NAV/5）被分散至组合MDD 35.45%。**不建议单策略满仓运行**。
2. **2023/2024 弱年**（-0.9%/+0.1%）：2板断板题材环境差时近乎零收益（好在不深亏）；策略依赖连板题材活跃度。
3. **H1流动性依赖**：买卖都在H1完成，若个股H1成交萎缩或跌停封死，退出顺延（deferred）承担隔夜风险。
4. **slot复用的引擎语义依赖**：+107.79% 的一半贡献来自当小时slot复用（笔数1.95x）；实盘执行必须支持"上午卖出后同日再买"，否则退化至对照版约+61%水平。
5. **成本红线**：≥0.3%/笔即显著降级（见§5成本表）。
6. **胜率46.4%偏低**：靠尾部盈利笔拉动，连亏段心理压力大，需纪律执行。
7. **毒区地图（Task#63败因解剖，1249笔板前特征归因）**：
   - **2板晚封板（seal_b2≥2，即H2后才触涨停）**：占28%，训练段笔均-0.20%（≥3时-0.61%）；反向过滤器F2（只留H1早板）引擎验证 +99.23%→+211.27%，训盲双升，已立v2候选待QA审批。
   - **2板巨量换手（turn_b2>45%）**：训练段笔均-2.81%、盲段去离群-1.53%，出货嫌疑毒区（用户猜想证实）；引擎F4过滤+121.86%但盲段回落，仅作实盘警示不进参数。
   - **首板一字（yizi_b1）**：训练段-1.41%，一字板无换手、承接结构差；盲段转正证据链弱，同为警示项。
   - **板前涨幅过高不是毒区**：ret20_pre>30%组训练段+1.10%为正（用户头号假说证伪），不应以"前期涨太多"为由放弃候选。
   - 全量分析见 `data/realtime/RESEARCH_B2A_FAILURE_ANATOMY.md`。
