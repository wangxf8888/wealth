## 2. 核心逻辑

### 信号条件（当日H1开盘时实时判断）

| 条件 | 要求 | 含义 |
|------|------|------|
| 板块 | 创业板(sz.30) / 科创板(sh.688) / 北交所(bj.) | 20%+涨跌幅=高波动 |
| 昨日涨幅 | >= 10% | 大阳线确认强势 |
| 昨日未涨停 | close/preclose < 涨停比例 | 非封板=仍可流动买入 |
| 今日低开 | open_rate <= -2% | 恐慌性低开=入场时机 |
| 今日open > 昨日low | 是 | 未跌破昨日最低支撑 |
| 近5日累计涨幅 | < 30% | 排除连续暴涨过热票 |
| 昨日换手率 | >= 3% | 确保有交投活跃度 |
| 换手倍数 | < 4.0倍(vs 5日均值) | V2新增：排除极端操纵放量 |
| 非ST | 是 | 排除退市风险 |

### 买入时机

- **时点**：当日Hour1 开盘（9:30）
- **价格**：H1_open（集合竞价结束价）
- **前提**：满足所有信号条件后立即买入

### 卖出规则

| 类型 | 触发条件 | 成交价 | 说明 |
|------|----------|--------|------|
| 硬止损 | 盘中LOW <= 买入价×0.94 | 买入价×0.94或open(取低) | -6%绝对保护 |
| Trailing Stop | 从peak回落 >= 2.0pp | 买入价×(1+(peak-2.0)/100) | V2核心：快速锁利 |
| 到期平仓 | hours_held >= 12 且 hour==4 | H4_close | 最长持有3天 |

**Trailing Stop机制详解**：
- 追踪持仓期间最高盈利点(peak_pct)
- 当盈利从peak回落2.0个百分点时触发卖出
- 例：peak达到+8%，回落到+6%时触发，锁定+6%利润
- T+1合规：买入当日不卖出

### 选股排序规则

- **昨日换手率降序**：高换手=市场关注度高=流动性好=日内波动大=trailing stop更易触发

## 3. 市场心理学/行为金融原理

### 对手方是谁？

**昨日追涨10%+后今日恐慌性减仓的短线客**。创/科板股票昨日涨10%+但未封板，意味着大量资金在高位介入但未被涨停板锁定（可卖出）。次日低开时，这些短线客的浮亏触发恐慌性止损，集中抛售在开盘前3分钟内完成，之后卖压急剧衰减。

### 利用了什么心理偏差？

1. **损失厌恶**：昨日追高买入者面临-2%以上的浮亏，心理痛苦放大约2.5倍（前景理论），导致过度抛售形成超跌。

2. **短视近因效应**：低开的瞬时恐慌遮蔽了"昨日大涨10%说明基本面/资金面有利"的中期逻辑。

3. **锚定在涨停预期**：散户昨日追入是期待今日封板，低开打破预期后情绪崩溃式出逃，形成过度反应。

### 为什么alpha不会很快消失？

1. **20%涨跌幅板块的特殊性**：创/科/北交所股票波动大，普通投资者不敢在低开后接盘，造成持续的"恐慌折价"。
2. **Trailing Stop的非线性退出**：传统策略用固定止盈/止损，2pp trailing能在脉冲式冲高后精确锁利，这需要小时级数据支撑。
3. **换手倍数过滤(V2)**：排除了"庄股操纵"式的异常放量，留下的是真正市场化的资金推动。

## 6. V2优化点

### V1基线表现
- CAGR: 172.30%, 611笔, 胜率49.92%, MDD 65.03%, 均收益+1.17%

### V2改进及效果

| 优化项 | V1 | V2 | CAGR变化 |
|--------|----|----|----------|
| Trailing Stop | 3.0pp | 2.0pp | 核心提升 |
| 硬止损 | -5% | -6% | 减少假止损 |
| 换手倍数过滤 | 无 | < 4.0 | 提升信号质量 |

### 为什么有效

1. **Trailing 2pp vs 3pp**：创/科板日内波动15-20%，冲高往往是短暂脉冲（持续15-30分钟），2pp比3pp更快锁利。3pp时经常出现"冲高+8%→回落+3%才触发→只赚3%"的遗憾，2pp则在"+8%→回落+6%"时就退出。
2. **硬止损-6% vs -5%**：20%涨跌幅板块日内正常波动可达-5%，-5%止损容易被"洗盘"触发后反弹错过。-6%多给1%呼吸空间，显著减少假止损。
3. **换手倍数<4**：当日换手率超过5日均值4倍时，往往是异常资金操纵（对倒、庄股出货伪装），这类票次日低开后大概率继续下杀。

## 7. 风险提示

### 最大回撤场景
- MDD 58.15%，主要发生在创/科板连续暴跌期间（如2022年初科技股杀估值）
- 单笔最大亏损可达-6%（硬止损）+ 滑点

### 策略失效的市场环境
- **创/科板系统性暴跌**：全板块普跌时低开后不反弹，持续杀跌
- **低波动环境**：涨10%+的股票数量极少，信号稀缺
- **流动性枯竭**：北交所个股可能出现流动性不足无法成交的情况

### 实盘注意事项
1. **开盘竞价参与**：需在9:25前挂单，竞价结束后自动成交
2. **板块识别**：严格只交易创业板(30xxxx)/科创板(688xxx)/北交所
3. **高波动心理准备**：20%涨跌幅意味着单日-15%也是正常波动
4. **trailing需实时监控**：每小时级bar结束后判断是否触发trailing stop
5. **资金量限制**：创/科小盘股流动性有限，建议单笔不超过该股日均成交额的1%
