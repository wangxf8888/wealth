## 2. 核心逻辑

### 信号条件（盘后生成候选池）

| 条件 | 要求 | 含义 |
|------|------|------|
| 昨日涨停 | close == 涨停价(主板10%/创科20%) | 确认涨停 |
| 非一字板 | open < 涨停价 | 排除无法买入的一字涨停 |
| H1早封 | hour1_close == 涨停价 | 第一小时即封死=极强抢筹意愿 |
| 低换手率 | 3% ≤ turn < 8% | 筹码高度锁仓=主力控盘；下限turn≥3过滤低质量信号(Task#40) |
| 非ST | isST字段过滤 | 排除退市风险 |
| 全板块 | 主板+创业板+科创板 | 不限板块 |

### 买入条件（T+1日 Hour1）

| 条件 | 要求 | 含义 |
|------|------|------|
| 必须低开>3% | open_rate < -3% | 恐慌性低开=过度反应=入场时机 |
| 今日H1不涨停 | h1_open < 涨停价 | 确保可买入 |
| 买入价 | H1_open | 9:30集合竞价结束价 |

### 卖出规则

| 类型 | 触发条件 | 成交价 | 说明 |
|------|----------|--------|------|
| Gap止盈 | 开盘price >= 买入价×1.04 | 以open成交 | 开盘跳空超TP |
| Gap止损 | 开盘price <= 买入价×0.85 | 以open成交 | 开盘跳空超SL |
| 盘中止盈(TP) | hourly HIGH >= 买入价×1.04 | 买入价×1.04 | SL优先检测(保守) |
| 盘中止损(SL) | hourly LOW <= 买入价×0.85 | 买入价×0.85 | 同小时双触发取SL |
| 到期平仓 | hours_held >= 4 且 hour==4 | H4_close | T+2尾盘强制退出 |
| 跌停处理 | 跌停封死时 | 跳过TP/SL | 到期仍以close退出 |

**SL优先设计（保守）**：跳空场景先判SL再判TP；盘中同小时TP/SL双触发时取SL（小时内OHLC顺序未知，保守处理）。

**跌停封死处理**：当bar_open <= 跌停价且bar_low >= bar_open时判定跌停封死，跳过TP/SL（无法以目标价成交），但到期仍强制以close退出。

### 选股排序规则

- **open_rate升序**（低开幅度最大优先）：跌幅越大=恐慌越深=反弹空间越大=alpha核心

## 3. 市场心理学/行为金融原理

### 对手方是谁？

**昨日追涨停板后今日恐慌抛售的"打板客"和跟风散户**。涨停板是A股最具吸引力的交易信号，吸引大量短线客在封板时抢筹。次日低开3%+意味着他们面临-3%以上浮亏，恐慌性止损在开盘前3分钟集中释放。但这些股票的基本面（强资金+高控盘）并未改变，卖压释放后修复概率高。

### 利用了什么心理偏差？

1. **"涨停必卖"的行为惯性**：大量游资和散户遵循"T+1涨停次日卖"的策略，形成可预测的抛压模式。当低开超3%时，这种抛压被恐慌情绪放大。

2. **可得性偏差**：投资者过度关注"低开=利空"的直觉判断，忽略了"H1早封+低换手=强控盘"的核心信息。真正控盘的主力不会因为3%的低开而改变策略。

3. **代表性偏差**：散户将"涨停后低开"等同于"见顶回落"，但H1早封+turn<8%的组合代表极强控盘，与"游资击鼓传花"的涨停有本质区别。

### 为什么alpha不会很快消失？

1. **"低开>3%才入场"的严格门槛**：大多数涨停策略在次日直接买入，不要求低开。3%的门槛大幅过滤了"正常溢价"的情况，只在真正恐慌时入场。
2. **H1早封+低换手的双重识别需小时级数据**：判断"第一小时就封板"需要hour1_close数据，这对散户和大多数量化平台是不可得的。
3. **低频信号(年均52笔)**：信号稀疏意味着不易被统计套利者发现和拥挤。

## 7. 风险提示

### 最大回撤场景
- MDD 56.24%，主要发生在2023年熊市（全年仅26笔且胜率30.8%，年亏-42.5%）
- 单笔最大亏损-15%（止损线）+ 可能的跌停无法成交风险

### 策略失效的市场环境
- **2023年系统性熊市**：涨停后低开>3%的信号极少（仅26笔/年），且低开后继续杀跌不反弹
- **涨停生态变化**：若市场涨停板减少（如注册制全面铺开），信号来源枯竭
- **监管限制**：若限制涨停板次日买入或打板策略，逻辑基础被破坏

### 实盘注意事项
1. **信号稀疏**：年均52笔（约每周1笔），大部分时间空仓等待
2. **开盘前决策**：9:25确认low开幅度，9:30前必须挂单
3. **跌停风险**：20%板块如果低开后继续杀至跌停，可能无法以-15%止损成交
4. **2023年教训**：熊市中信号质量骤降，需有全年亏损的心理准备
5. **与其他策略互补**：信号频率低但与其他4策略0%重叠，非常适合组合使用
6. **停牌股处理**：代码含停牌股回溯逻辑（往前多看5天找到真实的"前一交易日"）
