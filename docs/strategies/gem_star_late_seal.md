# 创科晚封涨停次日策略 (gem_star_late_seal)

## 1. 策略概览

| 指标 | 数值 |
|------|------|
| CAGR | **+152.92%** |
| 交易笔数 | 462 |
| 胜率 | 51.95% |
| 最大回撤(MDD) | 72.37% |
| 平均收益/笔 | +1.67% |
| 平均持仓 | ~8小时(2个交易日) |
| 回测区间 | 2021-01-01 ~ 2026-07-01 |

**一句话总结**：创业板/科创板昨日20%涨停且为"晚封"（H1未封板，盘中后段才封住）的股票，次日H1开盘买入，利用+12%/-20%的宽幅止盈止损+最长2天持有，捕获20%板晚封后的动量延续。

## 2. 核心逻辑

### 信号条件（盘后生成候选池）

| 条件 | 要求 | 含义 |
|------|------|------|
| 板块 | 创业板(sz.30xxxx) 或 科创板(sh.688xxx) | 仅20%涨跌幅标的 |
| 昨日涨停 | close >= prev_preclose × 1.20 (含0.01容差) | 昨日封板 |
| 非一字板 | open != close != 涨停价 | 排除无交易量的一字板 |
| 晚封板 | hour1_close < 涨停价 (含0.01容差) | H1未封住=盘中后段才封 |
| 非ST | isST字段过滤 | 排除退市风险 |

### 买入条件（T+1日 hour1）

| 条件 | 要求 | 含义 |
|------|------|------|
| 今日open < 涨停价 | 是 | 能买到（非一字开盘） |
| 今日open > 跌停价 | 是 | 非跌停封死（可成交） |
| 买入价 | H1_open | 9:30集合竞价结束价 |

### 卖出规则（日级TP-priority机制）

| 类型 | 触发条件 | 成交价 | 说明 |
|------|----------|--------|------|
| Gap止盈 | H1 open >= 买入价×1.12 | 以open成交 | 开盘跳空超TP |
| Gap止损 | H1 open <= 买入价×0.80 | 以open成交 | 开盘跳空超SL |
| 盘中止盈 | 每小时hourly HIGH >= 买入价×1.12 | 买入价×1.12 | TP优先检测 |
| 日级止盈(H4) | daily HIGH >= 买入价×1.12 | 买入价×1.12 | 补捕竞价区间极值 |
| 日级止损(H4) | daily LOW <= 买入价×0.80 | 买入价×0.80 | 仅H4检测 |
| 到期平仓 | hours_held >= 8 且 hour==4 | 当日close价 | 最长持有2天 |

**TP-priority设计**：每小时先用hourly high检测TP，只在H4用daily low检测SL。确保盘中TP有优先触发机会，避免"先触SL后反弹过TP"的误判。

### 选股排序规则

- **昨日换手率从低到高**：低换手 = 筹码高度锁仓 = 浮筹少 = alpha核心

## 3. 市场心理学/行为金融原理

### 对手方是谁？

**次日获利了结的短线封板客+被晚封涨停吸引追高的散户**。昨日在涨停价追入的打板客习惯性在次日开盘获利了结（"打板隔日卖"是游资标准动作），他们的集中抛售形成开盘短暂压力。但晚封板的真实多方力量更强（资金全天持续吸筹），卖压释放后价格继续走高。

### 利用了什么心理偏差？

1. **晚封 vs 早封的信息不对称**：散户认为"涨停就是涨停"不区分封板时间，但晚封意味着全天有大量真实交易和博弈后多方获胜，信息含量远高于早封/一字板。

2. **"涨停即卖"的行为惯性**：大量游资和短线客遵循"T+1涨停次日卖出"的铁律，导致次日开盘承压。但这种条件反射式卖出忽略了晚封板筹码结构的优势。

3. **高波动恐惧**：20%涨跌幅板块让普通投资者望而却步（"万一跌20%怎么办"），形成参与者壁垒，降低了交易拥挤度。

### 为什么alpha不会很快消失？

1. **20%板块的准入门槛**：大多数散户和保守资金不参与创/科板涨停股，竞争者有限。
2. **晚封识别需小时级数据**：判断"H1是否封板"需要小时级K线数据（hour1_close），普通行情软件不直接提供。
3. **宽止损(-20%)的心理门槛**：大多数人无法承受20%的止损设定，但这恰恰匹配了20%板块的高波动特性。

## 4. 关键参数表

| 参数 | 值 | 含义 |
|------|-----|------|
| buy_hour | 1 | H1开盘买入 |
| take_profit_pct | +12% | 止盈线(HIGH触发) |
| stop_loss_pct | -20% | 止损线(LOW触发) |

| 涨停判定容差 | 0.01元 | 兼容四舍五入误差 |

## 7. 风险提示

### 最大回撤场景
- MDD 72.37%是5策略中最大的，主要发生在创/科板连续暴跌+策略连续止损期间
- 单笔最大亏损可达-20%（止损线）+ 滑点
- 20%涨跌幅板块极端情况：涨停→跌停 = -33%日内振幅

### 策略失效的市场环境
- **2023/2026年市场风格转换**：信号质量下降，胜率降至47-51%
- **创/科板整体低迷**：缺乏涨停信号，策略处于空仓状态
- **流动性危机**：大面积跌停时无法以目标价止损

### 实盘注意事项
1. **开盘前确认**：9:25竞价结束后立即确认开盘价是否在涨停/跌停区间外
2. **MDD承受力**：72%MDD要求极强的心理承受力，强烈建议配合其他策略分散
3. **板块风险集中**：仅交易创/科两个板块，板块轮动时可能长期无信号
4. **sell_day_no_buy**：卖出当天不开新仓，可能错过连续信号
5. **日级TP-priority**：实盘中需在每小时bar结束时检查是否触TP，H4结束时补充用daily数据检测
